# Local sales leads — websites, LMS, portal management

Giga Developers / Giga Class Market ke liye **public** business contacts. Focus: Haripur, Abbottabad, Khanpur Dam, plus kuch Islamabad/Rawalpindi law & guest houses.

## Files

| File | Use |
|------|-----|
| `leads.csv` | Excel/Google Sheets mein kholo — naam, address, number, offer |
| `outreach-messages.md` | WhatsApp / SMS / Urdu copy-paste messages |

CSV ko Google Sheets mein **File → Import** se kholo, phir High priority se start karo.

## Numbers ke baare mein (zaroor parho)

Ye **owner ke ghar ke private numbers nahi** hain. Ye Google, hotel listings, school sites, aur District Judiciary Haripur ki **public bar list** se hain.

Chhoti hotels, guest houses, cafes aur advocates ke listed mobile **aksar owner/manager ke hote hain** — lekin call se confirm karo: *“Kya ye ownership/management ka number hai?”*

Har number **send se pehle verify** karo. Purane listings galat ho sakte hain.

**Spam mat karo.** Pehle call, phir 1 WhatsApp. Inquiry form **Services page** pe hai: https://gigaclassmarket.com/services/#inquiry — alag Contact page nahi. Agar stop kahe to band.

## Offer (ek line)

- Hotels: apni booking website, Booking.com ki commission kam
- Restaurants: apna menu + order system
- Schools: LMS, fee, attendance, parent login
- Hospitals: appointment + patient portal
- Lawyers: professional site + client inquiry portal

## Aur leads kaise nikaalo

1. Google Maps: `hotel Haripur`, `restaurant Abbottabad`, `advocate Haripur` — jin ki **website empty** ho
2. Facebook pages jin ka only phone/WhatsApp ho
3. Public bar list: https://districtcourtsharipur.net.pk/advocates/ (sirf chambers ko, bulk personal spam nahi)
4. Visit Main Bazar / GT Road / Jadoon Plaza — board pe number uthao, owner se baat karo
