# Stride — Coursera-style learning platform

Public visitor dashboard (landing) for a multi-role learning site:

- **Visitors** browse courses and topics
- **Students** (purchased courses) — coming next
- **Teachers** (upload courses) — coming next
- **Admins** (manage platform) — coming next

## Run locally

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
