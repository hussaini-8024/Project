# Pakistan Council — Site Pages Seed (v1.0.0)

Creates these published pages on **pkcouncil.org** (modeled on Giga Class Market structure, branded for Pakistan Council Organization):

- Home (set as front page)
- About
- Services
- Contact
- Privacy Policy
- Terms and Conditions
- Refund Policy

Each page includes SEO title + meta description.

## Upload (required)

StackProtect blocks this cloud agent from WP Admin, so **you must upload**:

1. Download `dist/PKC-Site-Pages-1.0.0.zip`
2. WP Admin → Plugins → Add New → Upload Plugin
3. Activate **PK Council Site Pages**
4. Pages appear under **Pages** immediately

Optional: Settings → Permalinks → Save (pretty URLs).
